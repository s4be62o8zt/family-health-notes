# 【红门·医事】40% 准妈妈中招！围孕期贫血不重视，可能拖慢宝宝发育

> 更新时间：2026-09-17 (UTC+8)

孕22周的李女士，本该满心欢喜感受宝宝胎动，可身体却频频 “掉链子”：走几步就喘得胸口发闷，爬两层楼梯得扶着墙歇好几回，连脸颊都没了往日气色，白得像蒙了层纸。

更让她慌神的是，饮食习惯竟也明显变化，这才惊觉：“不对劲，会不会影响宝宝？”直到产检单递来：血红蛋白仅 85g/L，是缺铁性贫血！

经医生指导调药、搭配饮食，一个月后复查，李女士可轻松走路。她牢记叮嘱：“孕期贫血早治，才能稳稳等宝宝来。”

而李女士遇到的情况并非个例 —— 很多准妈妈都会遭遇类似的 “健康小插曲”，想要从容应对，首先得读懂 “围孕期贫血” 究竟是什么。

从准备怀孕的前 3 个月，一直到宝宝出生后的 6 周，妈妈的血红蛋白（Hb）低于 110g/L，血细胞比容（HCT）低于 0.33，那就说明出现围孕期贫血了。

**0****1**
**围孕期贫血的 3 类 “小原因”**

1. 缺铁性贫血（最常见）：孕期宝宝发育 + 妈妈血容量增加，铁需求暴涨（孕晚期日需 7.5mg），饮食供不上；可能会出现：乏力、头晕、脸白、指甲脆、掉发多、“怪食咒”、活动后心慌气短。

2. 叶酸 / B12 缺乏性贫血：孕早期叶酸不足易致宝宝神经管畸形（如脊柱裂）；

3. 地中海贫血（遗传）：南方（粤 / 桂 / 琼 / 滇）高发，父母都带基因则宝宝可能患重症，治疗难、压力大；地中海贫血高发区夫妇孕前必做地贫筛查，给宝宝上 “健康锁”。

**0****2**
**贫血的影响**

对妈妈的影响：

1. 免疫力 “泄气”：产后易患子宫内膜炎、乳腺炎；

2. 分娩风险高：宫缩乏力，产程长，产后出血风险高；

3. 其他隐患：产后抑郁、贫血性心脏病等可能。

对宝宝的影响：

1. 先天条件差：可能成 “着急宝宝”（早产）或 “小豆芽”（低出生体重），出生后易生病、发育落后；

2. 大脑发育受影响，宝宝语言表达、认知能力比同龄娃差；出生后贫血。

**0****3**
**科学守护：分阶段呵护母婴健康**
根据围孕期不同阶段的特点，咱们可以用科学的方法，一步一个脚印地做好贫血防治工作，像守护 “小天使” 一样，守护妈妈和宝宝的健康。

1. 孕前：孕前 3-6 个月查血常规、血清铁蛋白（<30μg/L 需注意），地贫高发区加做地贫筛查；每天吃 0.4-0.8mg 叶酸至孕 3 月，缺铁遵医嘱补充铁剂；饮食：多吃瘦猪肉、牛肉、动物肝血，搭配橙子、猕猴桃等维 C 食物（“好搭档” 助铁吸收）。

2. 孕期：针对日常最常见的缺铁性贫血，若Hb正常，血清铁蛋白<30μg/L，提示铁耗尽的早期，应补充铁剂60mg/天，治疗后8周后评估疗效；轻度、中度缺铁性贫血（70＜Hb<110g/L），铁剂补充增至 100-200mg / 天，治疗2周后复查Hb评估疗效，治疗至Hb恢复正常后，应继续口服铁剂3-6个月；铁剂别和牛奶、咖啡、浓茶（“小克星”）同服，搭维 C 更高效，如铁剂不耐受或效果不佳，须静脉注射铁剂治疗；重度贫血（Hb<70g/L），及时住院输血治疗 ；饮食多吃红肉、动物血、黑木耳、紫菜，保证蛋白质助铁吸收。如非缺铁性贫血，请遵从医生专业指导，进行规范治疗。

3. 产后（分娩后 6 周）：产后复查血常规，若仍贫血，遵医嘱每天补 100-200mg 元素铁，至少坚持 3 个月；母乳喂养妈妈每天多补 50-100mg 元素铁，预防宝宝缺铁；多吃红肉、鸡蛋、豆制品、鱼类（富蛋白和铁）；若产后出血量多，及时告知医生处理，避免失血加重贫血影响恢复。

每个妈妈的身体情况都独一无二，具体的防治方法一定要咨询妇产科医生或专业营养师。
