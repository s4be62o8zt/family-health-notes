# 【健康加油站】春节团聚 警惕食物中毒！

> 更新时间：2026-09-16 (UTC+8)

**点击蓝字，关注我们**

新春佳节即将来临，探亲访友、聚会聚餐、外出旅游等活动明显增加，大家在与家人亲友团聚进餐时，一定要小心食源性疾病和食物中毒。

**一、食物中毒是什么？**

食物中毒是一种食源性疾病，是一种所进食物被细菌或细菌毒素污染，或食物含有毒素（俗称吃了“不干净”的食物）而引起的急性中毒性疾病。一般以腹痛、恶心、呕吐、腹泻、发热等症状为主。

**二、常见的食物中毒**

（1）蘑菇中毒：毒蘑菇含有植物性的生物碱，毒性比较强烈，一旦误食，可以损害肝、肾、心脏及神经系统，即使是微量毒素被吸收到体内也容易出现中毒的症状，如剧烈呕吐、腹泻并伴有腹痛、痉挛、流口水、突然发笑、进入兴奋状态、手指颤抖、出现幻觉等。

**蘑菇中毒急救措施：**

1. 120求助：立即拨打120急救电话，并保留毒蘑菇样品供救治人员参考。 

2. 补充体液：在等待救护车期间，为防止反复呕吐发生脱水，可饮用加入少量的食盐和食用糖的“糖盐水”，补充体液，防止休克。

3. 催吐、洗胃和导泻：为减少毒素的吸收，让中毒者大量饮用温开水或稀盐水，随后把手指伸进咽部催吐，可反复多次进行。

  注意：对于已发生昏迷的中毒者不要强行向其口内灌水，以免窒息。

（2）土豆中毒：如果土豆储存不当或者时间太久，就会开始发芽。一旦土豆发芽必须当心，发芽严重的土豆和无法判断发芽程度的土豆，坚决不要食用。因为发芽的土豆中含有一种叫龙葵素的毒素，尤其是发芽部位，毒素含量较高。这种毒素对人体胃肠道有强烈刺激，同时对呼吸中枢有麻痹作用，并可能会引起脑水肿等严重后果。食用几十分钟或几小时内即可发病，主要表现为咽喉部瘙痒、烧灼感、上腹部疼痛、恶心、呕吐、抽搐、呼吸困难，甚至呼吸停止等。

**急救措施**

1.症状较轻者：可饮用大量淡盐水、绿豆汤、甘草汤等解毒。

2. 中毒表现重者：应立即催吐，用手指、筷子等刺激咽部、舌根引起呕吐，饮用一些温水反复催吐，直至呕吐物为清水。

3. 呼吸衰竭者：立即人工呼吸急救。

4. 在上述处理的同时拨打120急救电话求助。

（3）亚硝酸盐中毒：亚硝酸盐中毒事件几乎每年都有发生。国内所发生的亚硝酸盐中毒事件的原因，大多数是将亚硝酸盐误当食盐食用而引起，少部分是食用尚未腌制成熟或已经变质的腌菜及其他含有亚硝酸盐的食物、水导致的中毒，此类中毒一般症状较轻。

**急救措施**

1.吸氧：使中毒者处于空气新鲜，通风良好的环境中，注意保暖。

2.催吐：进食时间短的可以催吐。用筷子或手指等轻轻刺激咽喉部，诱发呕吐。

3.送医：如病情严重，且中毒时间较长的，应速送医院进行抢救。

**三、急救小口诀**

食物中毒猛于虎，上吐下泻好痛苦，

催吐导泻留证物，未见好转把院入。

大家在享受美食的同时，一定要警惕食物中毒的危险。不吃不新鲜或有异味的食物；生熟食物要分开存放，水产品以及肉类食品应做熟后再吃；养成良好生活习惯，饭前便后要洗手。牢记中毒急救小口诀，让我们愉快安全过个年。
