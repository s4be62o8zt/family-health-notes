# 准备生三孩 先做做这份招“生”试卷吧

> 更新时间：2026-09-16 (UTC+8)

**孕产专家出题**

**看看您有没有当满分妈妈的潜质哦**

转自《洛阳晚报》记者 曾宇凌 通讯员 刘冰

受访专家 王晓若 洛阳市妇幼保健院孕产保健部主任、主任医师

当前，三孩生育政策引起广泛关注。其实对女人来说，从备孕到产检，犹如一次又一次的“小 考”，只为迎接当妈这场人生“大考”。想生个健健康康的宝宝，孕期知识必须掌握！今天，记者邀请我市孕产专家为正在备孕或已经 “好孕”的您，准备了一份“孕妈考卷”，题目都是必知的孕产知识，一起来答题闯关吧。

**第一部分：备孕篇 **（共3题，每题10分，共30分）

1.怀孕前三个月，最需要补充的是什么？

A 钙 B 叶酸 C 铁 

2.吃叶酸片，最好在一天中的什么时候？

A 早饭后 B 睡觉前 C 没有固定时间

3.有人说备孕要吃胖点，是这样吗？

A 为了宝宝，暂时胖点没什么  B 好不容易有理由不减肥了，没毛病  C 合理营养，过胖过瘦都不好

**第二部分：孕期篇** （共4题，每题10分，共40分）

1.孕期增重多少合适？ 

A 20公斤至22公斤  B 15公斤至18公斤  C 10公斤至12公斤 

2.妊娠期糖尿病在分娩后会消失吗？ 

A 不用担心，生完孩子就好了  B 一旦得了就摆脱不掉  C 不一定 

3.孕期感冒发烧了该咋办？ 

A 坚决不吃药，以免影响孩子  B 一般没啥事，扛扛就过去了  C 普通感冒多休息，高烧不退要就医 

4.做过剖宫产的女性，需要做B超排查疤痕妊娠吗？ 

A 需要 B 没必要

**第三部分：筛查篇** （共3题，每题10分，共30分）

1.唐筛主要为了筛查什么？ 

A 早产儿  B 唐氏儿  C 糖尿病患儿 

2.下面哪些人群能享受免费产前诊断？ 

A 35岁以上孕妇  B 血清学筛查18三体、21三体为高风险的孕妇  C 分娩过先天性严重缺陷婴儿的孕妇  D 以上都是 

3.新生儿筛查，采的是哪里的血？ 

A 指尖血  B 静脉血  C 足跟血 

**答案及解析**

**第一部分：备孕篇**

1、答案：B

解析：从怀孕前三个月开始补充叶酸，对于预防出生缺陷非常重要，能降低神经管畸形儿的发生率，包括脊柱裂、脑膨出等常见新生儿缺陷疾病。

2、答案：A

解析：吃叶酸片最好是早饭后半小时至一小时，更利于吸收。正常人群每天补叶酸0.4毫克就行，如果是既往生育过神经管缺陷儿的，则需每天补叶酸4毫克。

3、答案：C

解析：备孕期间确实要注意营养，但并不是吃得越多越好，过度肥胖反而可能影响备孕的成功率，还会对胎儿健康产生不利影响，所以建议将体重指数（BMI）控制在18～24Kg/m²的范围内。BMI计算公式为：BMI=体重（千克）除以身高（米）的平方。

**第二部分：孕期篇**

1、答案：C

解析：具体来说，整个早孕期一般建议增重1公斤至2公斤，中孕期和晚孕期每个月增长3斤至4斤就可以了。

2、答案：C

解析：妊娠期糖尿病的诱发因素之一就是孕期肥胖，这就是为什么强调孕期要合理增重。妊娠期糖尿病可能随着妊娠的结束而消失，也有可能变成慢性的。

3、答案：C

如果是普通感冒，孕妇不用太紧张，注意多喝水、多休息，因为感冒本身就是一种自限性疾病，没有特效药。但如果出现浑身疼痛、高烧不退等流感样症状，就一定要及时就医，该用药就用，避免发展为重症。

4、答案：A

解析：做过剖宫产手术、子宫肌瘤手术、多次流产的女性，怀孕后一定要做B超看孕囊着床位置，如果着床在原来切口的疤痕上，就属于疤痕妊娠，这种情况是比较危险的，所以要及早做B超排查。

**第三部分：筛查篇** 

1、答案：B

解析：唐筛是唐氏筛查的简称，主要目的是评估胎儿患唐氏综合征的风险。除了唐筛，NT检测、四维彩超、75克糖耐量试验也是必不可少的产检项目，不能推迟或省略，应按时间节点去医院。

 

2、答案：D

解析：很多人分不清产前筛查和产前诊断的区别，产前筛查是对胎儿进行的一个⻛险评估，产检时抽静脉血就能做，而产前诊断是指对高风险的胎儿进行进一步的确诊检查，要做一次羊膜腔穿刺，也就是羊水穿刺，进行染色体核型分析。

 

3、答案：C

宝宝出生72小时后，要做新生儿疾病抽血筛查，及早发现宝宝是否患有苯丙酮尿症、先天性甲状腺功能减低症等先天性代谢疾病，采血过程很快，取几滴足跟血就行了。
